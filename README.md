## 🚀 About me

Security practitioner working both sides. I break things in Hack The Box labs, then build the detections and hardening that would have stopped me.

- 🎓 **Current focus:** CISSP prep, privilege escalation methodology, WiFi/BLE attacks on ESP32
- 🏅 **Certs:** CompTIA CySA+ · CISSP (in progress)
- 🎯 **Goal:** build offensive tooling that makes defenders better
- 🧪 **On this GitHub:**
  - 🛠️ Post-exploitation tooling: loot collection and credential-reuse testing
  - 💥 Proof-of-concept exploits for published CVEs, with the root cause and the fix
